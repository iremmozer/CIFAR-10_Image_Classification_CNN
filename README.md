# CIFAR-10 Image Classification with CNN

In this project, we built a CNN model using the CIFAR-10 dataset. Since the data involves 10 different output classes, we set the number of neurons in the output layer to 10 and used the softmax activation function. Due to RAM limitations, we allocated 10,000 samples for training and 2,000 for testing. We also added a dropout layer to improve the model's learning performance. Subsequently, we fed a user-provided file path into the trained model to predict the object's name and concluded the project by evaluating the model's accuracy.
